# ÉNIGME 2 — Le mot de passe chiffré

## 📁 Contexte

Les enquêteurs ont découvert que Justine utilisait un espace **Google Docs personnel**, accessible à partir de son compte Google. Il pourrait contenir des documents importants pour comprendre sa disparition. Mais le compte est verrouillé par un mot de passe.

Près de son ordinateur, vous avez retrouvé un petit papier portant l'inscription **« Mot de passe — Docs »**. Une suite de lettres y est notée. Malheureusement, elle ne permet pas de se connecter : Justine semble avoir **chiffré** son mot de passe pour le protéger.

## 🔎 Mission

Déchiffrez la note et retrouvez le véritable mot de passe permettant d'accéder aux documents de Justine.

---

## Niveau 1 — Facile : un agent a commencé le travail

Sur le papier, vous lisez :

```text
FODYLHU
```

Un autre agent a reconnu un **chiffrement de César** : Justine a avancé chaque lettre de **3 positions** dans l'alphabet pour écrire cette note.

L'agent a déjà déchiffré la première lettre : **`F → C`**.

**Question :** En suivant le même principe, pouvez-vous retrouver les autres lettres et reconstituer le mot de passe ?

---

## Niveau 2 — Intermédiaire : un indice sur le chiffrement

Sur le papier, vous lisez :

```text
FODYLHU
```

Sur un coin de la note, Justine a écrit :

> « J'adore le chiffre de César, c'est si simple. Juste **3 positions vers l'avant** et c'est bon »

**Question :** À l'aide de votre journal de bord, retrouvez le mot de passe original.

---

## Niveau 3 — Difficile : retrouver la méthode et la clé

Sur le papier, vous lisez :

```text
FODYLHU
```

Un enquêteura a pu découvrir une indication supplémentaire :

```text
TEST → WHVW
```

Mais malheureusement il a eu un accident avant de pouvoir déchiffrer le mot de passe... Maintenat c'est à vous de le faire !

**Question :** Quelle méthode a-t-elle utilisée ? Déchiffrez ensuite le mot de passe.
